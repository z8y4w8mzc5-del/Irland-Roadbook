IRLAND ROADBOOK – TAG 1
31.08.2026 · Dublin Airport → Ard na Sidhe

Dateien:
- index.html: Haupt-App
- manifest.webmanifest: Installation als Web-App
- service-worker.js: Offline-Cache, sobald die App über HTTPS bereitgestellt wird
- icon-192.png / icon-512.png: App-Symbole

Test am Computer:
index.html im Browser öffnen. Vorlesen funktioniert abhängig vom Browser.

Für iPhone-Installation:
Die Dateien müssen über eine HTTPS-Webadresse bereitgestellt werden. Dann in Safari öffnen,
Teilen → Zum Home-Bildschirm → Als Web-App öffnen.

Wichtig:
Straßenhinweise im Roadbook sind Begleitinformationen. Für Live-Verkehr, Baustellen,
Umleitungen und konkrete Abbiegeanweisungen immer Apple Maps/Google Maps verwenden.
